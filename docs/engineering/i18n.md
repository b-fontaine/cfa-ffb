# Internationalisation (fr / en)

- Outil : `flutter gen-l10n` (configuration `app/l10n.yaml`).
- Sources : `app/lib/shared/l10n/app_fr.arb` (**modèle**, langue par défaut) et
  `app_en.arb`.
- Sortie : `app/lib/shared/l10n/generated/app_localizations.dart` (non versionnée,
  produite par `scripts/generate.sh`).
- Usage : `AppLocalizations.of(context).clé` ; importer
  `package:billard_cfa/shared/l10n/generated/app_localizations.dart`.
- `MaterialApp.router` expose `AppLocalizations.localizationsDelegates` et
  `supportedLocales` ; la langue suit l'appareil.

## Ajouter une clé

1. Ajouter la clé dans **`app_fr.arb` et `app_en.arb`** (mêmes clés, pas de texte en dur dans l'UI).
2. Paramètres : déclarer `"@clé": {"placeholders": {…}}` dans les deux fichiers
   (exemple : `sessionDurationMinutes`).
3. `scripts/generate.sh`, puis un scénario BDD qui vérifie le texte affiché.

## Ajouter une langue

Créer `app_<code>.arb` avec exactement les mêmes clés que `app_fr.arb`, ajouter un
scénario dans `app/test/bdd/localization.feature` (step
`the device language is {'<code>'}`).

## Garde-fou

`dart run scripts/check_l10n.dart app/lib/shared/l10n` échoue si un fichier ARB
a une clé manquante ou en trop par rapport au premier (ordre alphabétique) ;
exécuté par `scripts/check.sh --full` et la CI.
