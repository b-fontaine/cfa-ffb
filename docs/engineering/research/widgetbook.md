# Recherche — Widgetbook : version stable, API 3.x/4.0, intégration, migration et CI (état au 2026-10-11)

> Produit par un agent de recherche le 2026-10-11 (sources citées). **Les versions sont à revalider par `flutter pub get` avant usage.** Les faits de confiance `medium` ou `low` ne sont pas vérifiés dans le dépôt.

## Recommandation

Adopter Widgetbook 3.x stable : widgetbook ^3.25.0, widgetbook_annotation ^3.11.0, dev:widgetbook_generator ^3.24.0, dev:build_runner. Ne pas partir sur 4.0.0-beta.14 (API encore mouvante, mais plus adaptée long terme avec testWidgetbook ; à réévaluer à la sortie stable). Créer un projet séparé widgetbook/ (nom widgetbook_workspace) avec dépendance path vers app/, hors résolution du workspace de l'app pour éviter le conflit analyzer <14 (generator) vs >=14 (freezed 4.0.2, source_gen 4.3.0). Utiliser Widgetbook.material avec MaterialThemeAddon (thème clair/sombre de la charte FFB/Blackball), LocalizationAddon (fr/en), ViewportAddon (mobile + desktop), TextScaleAddon, optionnellement BuilderAddon + accessibility_tools. CI : pub get, build_runner, flutter analyze, flutter build web du sous-projet, et vérification que le code généré est à jour.

## Risques

- Conflit de dépendances analyzer (generator 3.24.0 <14 vs freezed 4.0.2 >=14) : non testé par pub get dans le dépôt ; peut imposer un projet hors workspace pub, voire attendre un generator autorisant analyzer 14 (la 4.0.0-beta.13 autorise 13/14 mais est une beta).
- Widgetbook 4 en beta avec ruptures possibles entre bêtas ; migration 3.x -> 4 manuelle/assistée par IA, non automatisable de façon déterministe.
- Pas de runner snapshot officiel en 3.x ; goldens dépendants de la plateforme (polices, rendu) donc instables entre machines locales et CI.
- Dates relatives pub.dev vérifiées via l'API JSON mais la documentation docs.widgetbook.io (site) n'a pu être lue que partiellement ; les docs ont été relues depuis le dépôt GitHub (branches main=3.x, v4=4.0), pas depuis le site rendu.
- L'ordre des addons influe sur le rendu ; AccessibilityAddon et DeviceFrameAddon sont dépréciés, ne pas les utiliser.
