# ADR 0012 — Réglages du club : valeur courante des règles, schéma v7, sauvegarde v2

- Statut : **accepté** (2026-10-15, livré), lot 9 (F8) ; conception dans [reglages-plan.md](../reglages-plan.md). Complète l'ADR 0003 (seuils = configuration) et l'ADR 0001 (schéma, sauvegarde).
- Contexte : `RulesConfig` est une valeur gelée au démarrage (`@lazySingleton`, `RulesConfig.standard()`), injectée dans 14 cas d'usage. Le seuil du rappel de sauvegarde (30 jours) est une constante de `BackupReminder`. L'animateur doit pouvoir régler 5 paramètres, durablement, et les retrouver après une restauration.
- Décision :
  1. **Modèle** : entité `settings` (`ClubSettings`, 5 entiers : `passesRequired`, `alertThreshold`, `recallStaleSessions`, `groupFailureSharePercent`, `backupReminderDays`). `ClubSettings` n'a **aucune validation propre** : `applyTo(RulesConfig base)` construit un `RulesConfig` et la validation reste celle du constructeur (`InvariantViolation(invalidRules)`).
  2. **`backupReminderDays`** (défaut 30, 1 à 365) rejoint `RulesConfig` : un seul endroit pour les bornes et les défauts. Les fenêtres statistiques, `persistentAlertThreshold` et les formes de séance ne sont pas exposés.
  3. **Valeur courante** : `RulesConfig` n'est plus un singleton mais une **fabrique** (`@injectable`, module `app/di/rules_module.dart`) qui lit `RulesStore.current` (`shared/lib`, singleton initialisé au lancement par `@preResolve` depuis `SettingsRepository`). Les cas d'usage, déjà des fabriques, gardent leur constructeur `RulesConfig` : aucun changement de signature, aucun test existant touché. `SaveSettings` écrit d'abord en base, puis remplace la valeur du `RulesStore`.
  4. **Stockage** : table drift `app_settings`, **une ligne** (`id = 1`, 5 colonnes entières NOT NULL, `updated_at`), hors conventions d'agrégat (comme `backup_exports`). Aucune ligne = valeurs par défaut ; « Rétablir » supprime la ligne. Schéma **v7**, migration `from6To7` additive.
  5. **Sauvegarde JSON** : clé `data.settings` (objet de 5 entiers), **facultative** ; `schemaVersion` du format passe à **2**, `supportedVersions = {1, 2}`. Une application plus ancienne refuse proprement un fichier v2 (`backupVersionUnsupported`) plutôt que d'en perdre les réglages en silence. Fichier sans `settings` : réglages en place **inchangés** (sur une installation neuve : défauts). Valeur hors bornes : `backupInvalid`, rien n'est écrit. Les réglages sont écrits dans la même `UnitOfWork` que les données.
  6. **Rétroactivité** : un réglage ne modifie aucun passage saisi (les passages restent des faits) ; il change les états dérivés (exercice validé, alertes, rappel, suggestion). L'écran le dit en une phrase.
  7. **Rappel de sauvegarde** : `BackupReminder.evaluate` reçoit `staleAfterDays` ; la constante `staleAfterDays = 30` disparaît (la valeur par défaut vient de `RulesConfig`).
- Alternatives écartées :
  - Remplacer `RulesConfig` dans les 14 cas d'usage par un fournisseur (`RulesProvider.current`) : 14 fichiers de production et ~15 fichiers de test touchés pour un gain nul tant que les cas d'usage sont des fabriques créées à l'ouverture de l'écran.
  - Table clé/valeur : non typée, valeurs hors bornes lisibles sans contrôle de schéma.
  - Réglages hors du fichier de sauvegarde : une restauration sur un autre appareil changerait silencieusement les validations d'exercices.
- Conséquences : une valeur lue par un cas d'usage est celle de sa création ; un bloc ou cas d'usage **conservé** à travers un changement de réglage verrait l'ancienne valeur. Les écrans actuels sont recréés à chaque navigation (`ShellRoute` + `context.go`). Les objets de longue durée (`RunSheetSessions`) ne conservent aucun `RulesConfig` : `ResolveRunPlan` lit `RulesStore.current` à chaque appel. Un test d'architecture interdit `RulesConfig` et `ResolveRunPlan` dans un singleton, à toute profondeur.
- Garde-fous : contrat commun in-memory / drift pour `SettingsRepository` ; test de migration v6 → v7 ; test que `RulesConfig` n'est pas enregistré comme singleton ; aller-retour de sauvegarde avec réglages, import d'un fichier v1 sans réglages, import refusé sans écriture partielle.
