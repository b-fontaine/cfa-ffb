# Base de connaissances — préparation de cours de billard

Point d'entrée pour tout agent ou contributeur qui prépare des séances. **Lire d'abord `00-provenance-et-fiabilite.md`.**

## Parcours de lecture recommandé

1. `00-provenance-et-fiabilite.md` — rangs de sources, étiquettes `[S]` `[FFB]` `[Web]` `[Prop]`, écarts connus.
2. `01-methode-pedagogique.md` — types de fiches, ordre et règles de séance.
3. `02-techniques/` — savoir de l'animateur (14 fiches techniques).
4. `03-exercices/` — initiation, entraînement, jeux (+ catalogue YAML).
5. `05-seances/` — contraintes enfants 90 min / adultes 120 min, modèles, progression.
6. `04-evaluation-et-suivi.md`, `06-contexte-federal.md`, `07-glossaire.md`, `08-lacunes-et-questions-ouvertes.md`.
