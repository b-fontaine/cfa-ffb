## Liste de contrôle (vérifiable)

- [ ] Somme des durées = 90 (enfants) ou 120 (adultes).
- [ ] Une seule notion principale.
- [ ] Ordre : notion/initiation → entraînement → jeu.
- [ ] Au moins deux exercices d'entraînement différents ; aucun prévu plus de 2 fois.
- [ ] Chaque exercice cite sa fiche source ; chaque durée interne est marquée `[Prop]`.
- [ ] Taux de réussite identiques à ceux de `entrainement.md`.
- [ ] Notion déjà introduite dans le cycle précédent (ou rappelée).
- [ ] Aucune affirmation non sourcée présentée comme règle fédérale.
