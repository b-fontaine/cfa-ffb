# Séances générées

Chaque fichier suit `docs/knowledge/05-seances/modele-seance.md`. Nommage : `AAAA-MM-JJ-<public>-<notion>.md` (ou `exemple-<public>-<notion>.md` pour les exemples).

| Fichier | Public | Durée | Notion |
|---------|--------|-------|--------|
| `exemple-enfants-demi-bille.md` | Enfants | 90 min | Demi-bille |
| `exemple-adultes-demi-bille.md` | Adultes | 120 min | Demi-bille |

Les durées internes sont des propositions `[Prop]` ; les exercices, taux et jeux sont `[S]`.
